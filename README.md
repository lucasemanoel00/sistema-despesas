# Controlador de Despesas

Projeto desenvolvido em Java com o objetivo de praticar Programação Orientada a Objetos (POO), utilizando estruturas de dados, enums e tratamento de exceções.

## Funcionalidades

- Cadastro de despesas.
- Busca de despesas por ID.
- Listagem de todas as despesas cadastradas.
- Remoção de despesas.
- Cálculo do total gasto.
- Cálculo dos gastos por categoria.
- Alteração da categoria de uma despesa.

## Tecnologias utilizadas

- Java
- HashMap
- Enum
- LocalDate
- Tratamento de exceções

## Categorias disponíveis

- Alimentação
- Transporte
- Lazer
- Educação
- Saúde
- Outros

## Como executar

1. Clone este repositório.
2. Abra o projeto em uma IDE compatível com Java.
3. Execute a classe `Main`.
4. Utilize o menu interativo para acessar as funcionalidades.

## Objetivo do projeto

Este projeto foi desenvolvido como parte dos meus estudos em Java e tem como objetivo colocar em prática os conceitos de POO, manipulação de coleções e validação de dados.

O projeto também serviu para desenvolver minha lógica de programação e organização de código.
